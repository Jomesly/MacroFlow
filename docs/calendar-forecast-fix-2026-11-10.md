# Calendar forecast repairs — 2026-11-10

> This records the focused C1/C2 repair. The subsequent C3–C7 repairs and current release recommendation are in [the production-readiness report](production-readiness-2026-11-10.md). Remaining-issue statements below describe this earlier checkpoint.

Both requested forecast defects (C1/C2) are repaired on `feature/dashboard`. No commit, push, deployment, or database migration was performed.

## Behavior

- Surprise scoring reads the frozen forecast returned from Supabase, rather than the current feed's forecast. A saved 0.3% forecast and a 0.4% actual still produce an upside inflation surprise if the feed later changes to 0.5% or removes the forecast.
- The archive freezes the **first usable numeric forecast**, preserving it on conflict. Genuine later pre-release revisions are also ignored under this conservative policy; this is not a latest-consensus revision history.
- Empty or unparseable forecasts do not create archive entries. A forecast first supplied after release cannot inherit an earlier empty event's timestamp.
- Inserts omit `first_seen_at`. The existing database default supplies receipt time. Neither request-start time nor a historical scoring `asOf` can backdate evidence. Historical calls can archive current observations, but only with their current database receipt time; the scoring cutoff still excludes unavailable evidence.
- A forecast must be recorded strictly before scheduled release. Equal timestamps, late timestamps, malformed timestamps, and absent archived forecasts are excluded.
- Existing unprefixed records are retained but excluded from scoring because their timestamps were supplied by the defective code. Repaired records use `consensus-v2:` IDs in the existing table. The SQL already run supports this without another migration.
- The merged-events cache key changes to `merged_events_v4`, avoiding reuse of surprises generated by the previous archive path. The scoring rules and model identifier are unchanged; this repair corrects calendar input provenance.
